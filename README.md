# Stock Golden Zone & Sentiment Analyzer

A Financial Data Science project that performs automated **Support/Resistance detection via `scipy.signal.find_peaks`**, calculates **Fibonacci Golden Zones**, and analyzes **News Sentiment**.
https://dime-assistant-3jhgvqgwbukns6ufxtpjs7.streamlit.app/
## Features
- Automatic Swing High / Swing Low detection using peak finding algorithms.
- Fibonacci Golden Zone (50.0% - 61.8%) identification.
- Web Scraping & NLP Sentiment Analysis for stock market news.
- Interactive Web Dashboard built with Streamlit & Plotly.
